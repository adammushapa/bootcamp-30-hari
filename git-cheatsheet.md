# Git Cheat Sheet
| Perintah | Fungsi |
|---|---|
| git status | Cek kondisi file |
| git add namafile | Masukkan ke staging |
| git commit -m "Pesan" | Simpan save point |
| git push | Kirim ke GitHub |
| git log --oneline | Lihat riwayat |
| git switch -c nama | Buat branch baru dan pindah ke sana |
| git switch nama | Pindah ke branch lain |
| git merge nama | Gabungkan branch nama ke branch aktif |
| git pull | Ambil perubahan terbaru dari GitHub |
| git branch -d nama | Hapus branch yang sudah digabung |
| git log --oneline --graph | Lihat riwayat dalam bentuk percabangan |
| git clone alamat-github | Salin repository dari GitHub ke laptop |
| git fetch | Cek perubahan di GitHub tanpa mengubah file |
| git fetch --prune | Bersihkan referensi branch yang sudah dihapus |
| git diff | Lihat perubahan yang belum di-commit |
